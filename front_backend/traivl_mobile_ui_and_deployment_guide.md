# 📱 Traivl 모바일 UI/UX 피드백 대응 및 배포·시연 가이드

> **작성일자**: 2026년 9월 1일  
> **대상**: Traivl 개발팀 전원  
> **목적**: 교수님 피드백(모바일 UI 최적화, 구글맵 연동, 실시간 GPS 및 배포 후 앱 구동)에 대한 검토 내용과 팀 실행 방안 공유

---

## 1. 교수님 피드백 주요 요약

1. **구글맵 연동 시 모바일 화면 미맞춤**: 데스크톱 접속 시 모바일 레이아웃 비율이 무너지거나 어색해 보임.
2. **Mobile-First 테스트 필수**: 개발 시 항상 모바일 뷰포트 환경(Chrome F12 모바일 모드 또는 스마트폰 실기기)에서 테스트할 것.
3. **모바일 UI/UX 최적화 우선**: 사용자가 여행지에서 스마트폰으로 앱을 사용할 때 최상의 경험을 제공하도록 UI 우선순위 조정.
4. **배포 시 일관된 화면 출력 및 실제 앱 구동 시연**: 모든 기기에서 보기 좋은 동일한 UI가 출력되고, 배포 후 실제 모바일 앱처럼 동작해야 함.

## 2. 핵심 질의응답 (Q&A)

### Q1. 배포 후 모바일에서 "가자" 버튼을 누르면 구글 지도 앱으로 연동되나요?
**A. 네, 모바일 환경에서는 설치된 구글 지도 앱으로 자동 전환됩니다.**

* **원리**: 현재 적용된 구글 지도 딥링크(`https://www.google.com/maps/dir/?api=1&...`)는 모바일 OS(iOS/안드로이드)의 유니버설 링크(Universal Links) 규격입니다.
* **동작 방식**:
  * **PC/노트북**: 구글 지도 웹사이트 새 탭으로 이동
  * **스마트폰(iOS/Android)**: 스마트폰에 설치된 **'구글 지도(Google Maps) 네이티브 앱'이 즉시 열리고 길안내 자동 시작**

---

### Q2. 실제 여행지에 갔을 때 사용자 핸드폰 GPS로 실시간 경로 추천이 가능한가요?
**A. 네, 이미 시스템 내부 로직으로 구현 완료되어 있습니다.**

`JourneyMap.tsx` 내 지능형 거리 감지 로직 작동 구조:
* **국내 사전 플래닝 모드 (목적지 거리 100km 초과)**:
  * 한국 자택/학교에서 일본/해외 일정 작성 시, 자동으로 가상 출발지(역/공항)를 기준점으로 설정하여 경로 미리보기 제공.
* **현지 실시간 길안내 모드 (목적지 거리 100km 이내)**:
  * 사용자가 해외 여행지 현지에 도착하면 **스마트폰 실제 GPS 좌표(`realLat`, `realLng`)**를 출발지로 자동 인식하여 실시간 현지 기준 경로 안내 및 구글맵 연동 수행.

---

### Q3. 배포 후 교수님께 "실제 앱"으로 보여주려면 어떻게 해야 하나요?
**A. PWA(Progressive Web App) 기술을 적용하여 브라우저 틀이 없는 100% 풀스크린 앱으로 시연합니다.**

* 웹 서비스로 배포하되 스마트폰 **'홈 화면에 추가'** 기능으로 설치하면, 브라우저 주소창이나 메뉴 틀 없이 **네이티브 카카오/네이버 앱처럼 독립된 앱(Standalone)** 형태로 켜집니다.

## 3. 코드 반영 및 기술 조치 내역

팀원 공유를 위해 프로젝트에 즉시 반영한 PWA 및 모바일 뷰포트 설정 내역입니다:

1. **`public/manifest.json` 생성**:
   * 앱 이름(`Traivl - AI 여행 길잡이`), 테마 색상(`#8c52ff`), 단독 실행 모드(`"display": "standalone"`) 정의.
2. **`app/layout.tsx` 메타태그 강화**:
   * iOS/Android 전용 모바일 풀스크린 및 핀치 줌 방지 메타태그 추가.
   * `apple-mobile-web-app-capable`, `viewport-fit=cover`, `maximum-scale=1.0` 반영.
3. **`globals.css` 모바일 컨테이너 보완**:
   * `.app-container`에 `max-width: 480px; margin: 0 auto;`가 적용되어 있어 PC 접속 시에도 중앙 스마트폰 목업 프레임으로 정돈되어 출력됨.

## 4. 팀 실행 계획 (Action Items)

### 📌 Step 1. Vercel 클라우드 무료 배포 (HTTPS 주소 생성)
* 프로젝트 루트에서 아래 명령어 실행하여 배포 진행:
  ```bash
  npm install -g vercel
  vercel
  ```
* 배포 완료 후 생성되는 HTTPS 주소(예: `https://traivl.vercel.app`) 확보.

### 📌 Step 2. QR 코드 및 스마트폰 테스트
* 배포된 HTTPS 주소를 QR 코드로 변환.
* 팀원 스마트폰으로 QR 코드 접속 후:
  * **아이폰**: 사파리 ➔ [공유] ➔ **'홈 화면에 추가'**
  * **안드로이드**: 크롬 ➔ [더보기] ➔ **'앱 설치' 또는 '홈 화면에 추가'**
* 바탕화면의 `Traivl` 앱 아이콘으로 접속하여 아래 4대 네이티브 기능 정상 동작 확인:
  1. 주소창 없는 전체 화면(Standalone) 구동
  2. 스마트폰 카메라/마이크 연동 (사진/음성 번역)
  3. "가자" 버튼 클릭 시 구글 지도 앱 자동 호출
  4. 스마트폰 실시간 GPS 연동

### 📌 Step 3. 교수님 최종 시연
* 교수님께 QR 코드를 제시하여 스마트폰으로 접속 및 [홈 화면에 추가] 진행 후 시연.
* (필요 시) 안드로이드 전용 APK 파일 제출 요구가 있을 경우 Capacitor(`npx cap add android`) 패키징 진행 예정.
